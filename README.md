# 空靈次元 · Ethereal Dimension

A self-evolving **AI digital pet** that lives 24/7 on your Mac Studio. Each pet
looks unique (procedural vector art from a seed), grows on its own in real time,
has a name, and murmurs short "ethereal whispers" generated by a **local LLM**
running on the Mac (free, unlimited, private). You play from your **phone** —
the web app installs as a full-screen PWA and connects back to the Mac from
anywhere over Tailscale.

> Single-player today; the data model and API already reserve hooks for
> co-raising pets with others (multiplayer).

## Architecture (one process, one machine)

```
phone (PWA)  ──https──▶  Mac Studio
                          ├─ Fastify  : REST + SSE + serves the PWA
                          ├─ SQLite   : pets + whispers (survives restarts)
                          ├─ Ticker   : 60s authoritative simulation loop (24/7)
                          └─ Ollama   : local LLM for whispers (free tokens)
```

- `packages/core` — pure, isomorphic simulation + procedural SVG (runs on both server and browser)
- `packages/server` — the always-on backend
- `packages/web` — the mobile-first PWA

The pet lives on the server: it ages whether or not anyone is watching, and
catches up exactly after any downtime (state is derived from elapsed time).

## Quick start (run it on the Mac Studio)

Requires Node 20+ and (optionally) [Ollama](https://ollama.com).

```bash
# 1. install deps
npm install

# 2. configure
cp .env.example .env
#   - set AUTH_TOKEN to a long random string (needed for phone access):
#       openssl rand -hex 32
#   - OLLAMA_MODEL defaults to qwen2.5

# 3. (optional but recommended) start a local model
ollama pull qwen2.5
ollama serve            # usually already running on macOS

# 4. build + start the 24/7 server (it serves the PWA too) — one command
npm start
```

Open `http://localhost:4711` on the Mac. **Summon** a pet and it begins to live.

> No Ollama? Everything still works — whispers fall back to in-character
> templates, and the pet simulation is unaffected.

## Play from your phone

See **[deploy/README-network.md](deploy/README-network.md)** for the full guide.
The short version (recommended): install **Tailscale** on the Mac and the phone,
run `tailscale serve` to get an HTTPS address, open it on the phone, enter your
`AUTH_TOKEN`, and **Add to Home Screen** for a full-screen app. Works on Wi-Fi
and cellular.

## Run it 24/7

Load the launchd service so the backend starts on boot and restarts on crash —
see **[deploy/README-network.md](deploy/README-network.md)** and
`deploy/com.yao.pet.plist`.

## Develop

```bash
npm run dev:server     # backend with reload (tsx watch)
npm run dev:web        # Vite dev server (proxies /api to :4711)
npm test               # core simulation unit tests
npm run typecheck      # all packages
```
