# 功能規格：Pinterest 逆向 Prompt → Notion（給 AI 工房整合用）

單檔實作在 `pinterest_to_notion.py`，可整檔搬走。本文件說明它的**輸入/輸出契約**，方便你在 AI 工房用任何框架（CLI、HTTP 服務、agent tool）包起來。

## 一句話

給 Pinterest 看板/使用者網址 → 抓圖 → Claude 與 AI 工房雙模型逆向出生成 prompt → Claude 裁判算信心 → 過門檻寫入 Notion。

## 環境變數契約

| 變數 | 必填 | 說明 |
|---|---|---|
| `ANTHROPIC_API_KEY` | ✅ | Claude（逆向 + 裁判） |
| `CLAUDE_MODEL` | | 預設 `claude-opus-4-8` |
| `AI_WORKSHOP_BASE_URL` | ✅ | 工房 OpenAI 相容端點，結尾含 `/v1` |
| `AI_WORKSHOP_API_KEY` | | 預設 `local`（本機伺服器多半不驗證） |
| `AI_WORKSHOP_MODEL` | ✅ | **看得懂圖**的模型名 |
| `NOTION_API_KEY` | 寫入時✅ | Notion integration token |
| `NOTION_DATABASE_ID` | | 預設既有資料庫 `e771e46f-…` |
| `CONFIDENCE_THRESHOLD` | | 預設 `0.75` |
| `PINTEREST_STORAGE_STATE` | | 私人看板的 Playwright 登入狀態檔路徑 |
| `MAX_PINS` / `SCROLL_ROUNDS` | | 每來源抓圖上限 / 捲動次數 |

## AI 工房 API 契約（關鍵）

工房只要符合 **OpenAI `POST {base_url}/chat/completions`**：

請求（程式送出的）：
```json
{
  "model": "<AI_WORKSHOP_MODEL>",
  "max_tokens": 1024,
  "messages": [{
    "role": "user",
    "content": [
      {"type": "text", "text": "<逆向指令，要求輸出 JSON>"},
      {"type": "image_url", "image_url": {"url": "data:image/jpeg;base64,...."}}
    ]
  }],
  "response_format": {"type": "json_object"}
}
```
回應需可由 `choices[0].message.content` 取到字串，內容是逆向 JSON。
> 模型必須是**多模態/看圖**（Qwen2-VL、Llama 3.2 Vision、MiniCPM-V、LLaVA…）。純文字模型會失敗。
> 若工房不是 OpenAI 相容，只改 `analyze_with_workshop()` 一個函式即可，其餘不動。

## 模型須回傳的 JSON（兩個逆向模型共用）

```json
{
  "name": "8 字內中文短名",
  "prompt": "詳盡英文生成 prompt",
  "industry": "房地產 | 節慶 | null",
  "category": "社群貼圖 | null",
  "style_tags": ["莫蘭迪綠", "..."],
  "confidence": 0.0,
  "reasoning": "一句話"
}
```
`industry / category / style_tags` 不在允許清單內的值會被自動丟棄（清單見檔頭 `ALLOWED_*`）。

## 核心函式（可單獨呼叫）

| 函式 | 輸入 → 輸出 | 用途 |
|---|---|---|
| `scrape(url, max_pins=, scroll_rounds=)` | str → `List[Pin]` | 抓 Pinterest |
| `download_image(url)` | str → `(bytes, mime)` | 下載圖 |
| `analyze_with_claude(image, mime)` | → `Analysis` | Claude 逆向 |
| `analyze_with_workshop(image, mime)` | → `Analysis` | AI 工房逆向 |
| `cross_validate(image, mime, a, b)` | → `Validation` | 裁判 + 信心分數 |
| `passes(validation, threshold=)` | → `bool` | 門檻判斷 |
| `process_pin(pin)` | `Pin` → `Record` | 跑完整一張圖 |
| `build_properties(record)` | → `dict` | 組 Notion payload |
| `NotionWriter().exists/create` | | 去重 / 寫入 |
| `run(urls, dry_run, threshold, max_pins)` | | 整批編排（CLI 用） |

信心公式：`final_confidence = agreement × mean(兩模型自評信心)`；`passes` 需 `prompt` 非空且分數 ≥ 門檻。

## 三種整合方式

1. **直接 CLI**：`python pinterest_to_notion.py <url> [--dry-run] [--threshold 0.8] [--max-pins 20]`
2. **當函式庫**：`import pinterest_to_notion as p; p.run([...], dry_run=False, threshold=0.8, max_pins=20)`
3. **包成工房 tool / HTTP**：呼叫 `process_pin(pin)` 拿 `Record`，自行決定要不要 `NotionWriter().create(record)`。

## Notion 欄位對應

名稱←合成短名；原圖←Pinterest 原圖外連；來源出處←pin 網址（去重鍵）；逆向 Prompt←合成 prompt；產業用途/類別←分類；風格標籤←標籤；備註←信心/一致性/各模型自評/分歧。
