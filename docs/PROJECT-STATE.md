## 一、這是什麼（核心概念，2026 最新定調）

**不是「電子寵物」，是一顆會自己成長的「靈性源質」。**
- 一顆獨一無二、程式化生成的**量子靈質**（發光機率雲核心＋電子軌道＋冷電光譜），在「時空」中漂浮（XYZ 飄移）。
- **24h 自運、自己成長**（人不在也在長；回來自動補算）。
- **成長必須肉眼隨時可見**（重點 / 待強化）：要能一眼看出它比剛才更「大／更豐富」——連續的體積漸增、軌道/粒子/細節持續累積，而不只是階段跳變或數字條。
- 奉行使用者的《空靈經》精神：去聖、寧靜、超脫；成長歷經七卷（卵→空→我→知→戲→手→行→圓）。

## 二、現況（做到哪）

- **可玩**：本地網頁 + 後端 24h 常駐；手機/桌機皆可（桌機沉浸滿版）。
- **視覺**：量子靈質（**已去除人臉概念**，改為抽象脈動核＋內部火花＋果凍晃動＋軌道），冷電光譜配色，沉浸星雲背景，玻璃 UI，放大按鈕。已用無頭瀏覽器截圖驗證，視覺 OK。
- **音**：WebAudio 合成環境音（drone + 生成式五聲微光）——氛圍可，但**非記憶點旋律**，待升級。
- **互動**：餵養/安撫/凝視/命名 + 反應動畫 + 音效。
- **低語（LLM）**：本地 Ollama，三分身（衙墨/寂照/映塵）輪轉；沒裝 Ollama 則用模板。
- **一鍵更新按鈕**：`更新` 鈕（`POST /api/update` → git pull + 重建）。**首次仍需 SSH pull 一次拿到修好的按鈕，之後點按鈕即可。**
- **自運工作室**：`.claude/skills/` 有 game-producer / game-designer / game-artist / playtester；每小時 cron 自動優化（session 內）。
